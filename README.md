# 屁眼派對 · 數位分身

我們家的數位分身：可編輯的平面圖（支援 L 型房間）、3D 全覽、把照片釘在拍攝位置的照片牆，以及全屋坪數計算。

## 本機使用

```bash
python serve.py 5173
```

打開 http://localhost:5173 。格局存在 `home-data.json`，照片存在 `photos/`。

## 雲端（Vercel）

- 任何人都可以唯讀瀏覽。
- 按右上角「🔒 編輯」輸入編輯密碼（環境變數 `EDIT_KEY`）才能修改格局、上傳照片。
- 格局與照片存在 Vercel Blob；每次儲存都保留一個版本（最近 30 版），刪除的照片會先複製到 `trash/`。
- `home-data.json` 是雲端第一次啟動時的初始格局。
